### 3.2 09:30–11:00｜T1 + T2：Flex 持久化与单价显示

**验收动作**（注意顺序——UI 上模型列表只有裸名，`:flex` 是点选瞬间按开关拼接的，不存在"先选带 :flex 的模型"这一步）：

1. 打开模型选择器，**先开启 Flex 开关**。
2. 点选任意 OpenRouter 模型 → 提交的模型串应为 `model:flex`。
3. 关闭并重新打开模型选择器，重复 3 次 → 开关每次都仍是开（不再被洗掉）。
4. 再点选一次 → 仍拼接 `:flex`。
5. Flex 行副标题可见当前档单价（`约半价 · $x/$y per 1M`）；缺价目/空元数据显示"—"且不崩溃。

**通过标准**：

- [ ] 重开弹层 3 次后开关仍为开，点选仍提交 `:flex`

这个周末可以把 AI 当"执行助手 + 校对员"，但关键结论必须由人确认。

**适合交给 AI**：整理账单 CSV 和统计口径、生成对账脚本草稿、汇总测试输出、检查 Markdown 链接/锚点/数字一致性、起草 ASSESS/MASTER-PLAN 更新段落、把真机步骤整理成 checklist。

**不交给 AI**：判断真机是否真的通过、判断摘要质量是否明显下降、决定是否发版、决定是否默认开启某个开关、在样本不足时替你做确定性结论。

## 6. 风险与预案
