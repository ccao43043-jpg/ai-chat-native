## 3. 保留的风险，不在本次改功能

- **AutoChar S3 不完整**：world scope 核心正确不等于所有 UI/交互已接；世界切换重询、忽略提示后重进、off 的全路径、真实模型不破坏世界设定均需专项验收。
- **统一召回仍灰度关闭**：先证明显式开启/关闭的请求内容和预算传导，再决定是否默认启用。slots 冲突目前观测不阻断。
- **发布验证边界**：CI 未持有固定 key，产物是临时 debug 证书；R8 成功编译不证明 serializer/枚举运行时完整，须签名核验和 release 装机 smoke。
- **数据路径残余**：`returnDefaultValues=true` 还在，真实 KeyStore 缺专门覆盖；`BackupService.restore` 先删后写且 `fs.set` 失败只影响计数，正常往返测试不能证明磁盘满/中断时原子恢复。保留故障注入/恢复核查待办，不宣称本次已复现数据丢失。
- **图片容量与文件长度**：`BlobStore.gc` 暂无生产调用，旧图懒迁移不等于磁盘自动回收；120k 字符之外不参与检索，旧已截断附件不能凭空恢复全文。后续先做容量/实际文档观察，不另造图库项目。
- **CI 权限与门禁**：`android.yml` 为失败日志分支保留 `contents: write`，仍有 `git push -f origin ci-logs` 的历史实现；本次没有触发或修改它。lint/detekt 与 release 运行时未成为门禁；最小权限待评估。
- **行为登记滞后**：本轮将已存在的文件检索、CAS、可选上下文/AutoChar 作用域补入规格差异登记；不是授权新行为。算法计划 D1–D11 与规格 §3.5 的 D 编号是两套编号，不混用。
